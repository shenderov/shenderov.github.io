# Contributing to shenderov.github.io

First off, thanks for your interest in contributing!

## How Can I Contribute?

### Reporting Bugs

- Open an issue with a clear title and description.
- Include steps to reproduce the issue if possible.
- Add screenshots or logs if helpful.

### Suggesting Enhancements

- Open an issue describing your idea or enhancement.
- Explain why it would be useful.

### Pull Requests

1. Fork the repository and clone your fork.
2. Create a new branch for your feature or bugfix.
3. Make your changes and test them locally:
   - Run `bundle install` if needed.
   - Start the site with `bundle exec jekyll serve`.
4. Commit your changes and push your branch.
5. Open a pull request with a description of what you changed.

#### Guidelines

- Keep code style consistent with the existing project.
- If updating the UI or structure, please provide before/after screenshots.
- Reference relevant issues if applicable.

## Code of Conduct

Be respectful and considerate of others. Harassment or abusive behavior will not be tolerated.

---

Thank you for helping make this project better!
